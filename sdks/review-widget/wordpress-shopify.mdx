Use these CMS options when you cannot ship a custom React build. Create keys under **Integrations → API keys** and (optionally) a widget under **Integrations → Review widgets** first.

## Who this is for

Marketers and agencies embedding EthioReview on WordPress or Shopify storefronts.

## WordPress

Install the EthioReview Widget plugin, then add the shortcode to any page or post.

### Shortcode

```
[ethioreview_widget biz="org_123" key="pk_live_..." widget="widget_abc"]
```

| Attribute | Required | Description |
| --------- | -------- | ----------- |
| `biz` | One of | Organization profile ID (`data-business-id`) |
| `key` | Yes | Publishable key (`pk_test_*` or `pk_live_*`) |
| `widget` | One of | Registered widget ID (preferred when set) |
| `base` | No | API base URL (default `https://api.ethioreview.com`) |
| `script` | No | Widget script URL (default `https://cdn.ethioreview.com/widget.js`) |

When `widget` is set, it takes precedence over `biz`.

### Sandbox example

```
[ethioreview_widget key="pk_test_YOUR_KEY" widget="YOUR_SANDBOX_WIDGET_ID"]
```

Add your WordPress site origin (for example `https://yoursite.com`) under **Integrations → API keys → Allowed origins**.

## Shopify

Add the EthioReview review widget Liquid snippet to your theme (or theme app extension). Configure the block / section settings:

| Setting | Description |
| ------- | ----------- |
| `public_key` | Publishable key from **Integrations → API keys** |
| `business_id` | Organization profile ID |

Ensure the storefront origin is on the API client's allowed origins list.

## CDN script

Both CMS paths ultimately load the Web Component from:

```html
<script async src="https://cdn.ethioreview.com/widget.js"></script>
```

## One failure mode

**Shortcode renders an empty box** — usually a missing allowed origin or a sandbox/production mismatch (`pk_test_*` with a production `widget`). Fix under **Integrations → API keys** and **Integrations → Review widgets**.
