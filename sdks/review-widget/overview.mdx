Install packages from npm — see [Widget packages](/sdks/review-widget/packages) for the full list. Create keys under **Integrations → API keys** before you wire any package.

## Packages

| Package | Description |
| ------- | ----------- |
| `@ethioreview/review-widget-core-client` | HTTP client, types, telemetry |
| `@ethioreview/review-widget-core` | Re-exports + `WidgetApiClient` |
| `@ethioreview/review-widget-web-vanilla` | Web Component + script loader |
| `@ethioreview/review-widget-web-iframe` | iframe helpers |
| `@ethioreview/review-widget-react` | React components |
| `@ethioreview/review-widget-next` | Next.js SSR + JSON-LD |
| `@ethioreview/review-widget-react-native` | WebView embed helper |

## Core client

```typescript
import { CoreClient } from "@ethioreview/review-widget-core-client";

const client = new CoreClient({
  baseUrl: "https://api.ethioreview.com",
  publicKey: "pk_live_...",
});

const data = await client.fetchReviews("org_abc", { limit: 5, minStars: 4 });
// data.reviews[].reviewUrl → EthioReview deep link
```

## Next.js

```typescript
import {
  getWidgetReviewsServerData,
  buildAggregateRatingJsonLd,
} from "@ethioreview/review-widget-next";

export async function getStaticProps() {
  const reviews = await getWidgetReviewsServerData({
    baseUrl: process.env.ETHIOREVIEW_API_URL!,
    publicKey: process.env.ETHIOREVIEW_PUBLIC_KEY!,
    businessId: process.env.ETHIOREVIEW_ORG_ID!,
  });
  return { props: { reviews } };
}
```

Full guide: [Next.js embed](/integrations/widget/embed-next).

## Marketplace pages

Use the widget for **platform** and **shop** pages (`businessId` = marketplace or vendor org). For **product** SKU pages, fetch reviews with the partner SSR API so the rating stays product-scoped:

```bash
curl -H "Authorization: Bearer sk_test_YOUR_SECRET" \
  "https://api.ethioreview.com/api/v1/partner/platform/shops/vendor_42/products/sku_1001/reviews"
```

Full guide: [Display reviews](/integrations/digital-platform/display-reviews).
