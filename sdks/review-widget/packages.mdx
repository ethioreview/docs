---
title: Widget packages
description: NPM package reference for EthioReview review widget SDKs.
---

Install only the packages you need. All public widget calls use base URL `https://api.ethioreview.com` (or `https://api.ethioreview.com/api/v1` for REST paths) with a publishable key from **Integrations → API keys**.

## @ethioreview/review-widget-core-client

Shared types and HTTP client.

- `CoreClient` — `fetchReviews`, `fetchRating`, `resolveWidget`
- Types: `WidgetReview`, `WidgetReviewsResponse`, `WidgetAuthor`
- Sends `X-Widget-Key` header automatically

## @ethioreview/review-widget-core

Re-exports core client helpers plus `WidgetApiClient` and embed snippet builders (`buildReactEmbedSnippet`, and related utilities).

## @ethioreview/review-widget-web-vanilla

- `ReviewWidgetElement` — custom element `<review-widget>`
- `registerReviewWidget()` — register custom element
- `buildScriptEmbedSnippet()` — copy-paste HTML

CDN script: `https://cdn.ethioreview.com/widget.js`

## @ethioreview/review-widget-react

- `ReviewWidget` — data-fetching container with layout support
- Layout components (`HeroReviewBanner`, `TrustScoreSummary`, …)
- `createReviewWidgetConfig` — typed config from env vars
- Stylesheet: `@ethioreview/review-widget-react/styles.css`

## @ethioreview/review-widget-next

- `getWidgetReviewsServerData` — SSR fetch by `businessId`
- `getWidgetResolveServerData` — SSR resolve by `widgetId`
- `buildAggregateRatingJsonLd` / `toJsonLdScript` — SEO helpers

See [Next.js embed](/integrations/widget/embed-next).

## @ethioreview/review-widget-web-iframe

- `buildIframeSnippet()`
- `attachIframeResizeListener()`
- Frame URL: `https://cdn.ethioreview.com/widget-frame.html`

## @ethioreview/review-widget-react-native

- `ReactNativeReviewWidget` — WebView wrapper
- `getWidgetWebViewUrl` — build frame URL

See [React Native](/sdks/review-widget/react-native).
