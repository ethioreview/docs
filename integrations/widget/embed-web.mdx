The Web Component is a custom element (`<review-widget>`) you can drop into any HTML page, CMS, or static site.

## Who this is for

Sites without a React toolchain — plain HTML, WordPress, Shopify themes, Webflow custom code, and similar.

## Dashboard steps

1. **Integrations → API keys** — create a key; add your site origin
2. **Integrations → Review widgets** — create a matching-environment widget (optional but recommended)
3. **Integrations → Sandbox test** — copy the HTML snippet while testing

## Install

```bash
npm install @ethioreview/review-widget-web-vanilla
```

Or load from CDN:

```html
<script async src="https://cdn.ethioreview.com/widget.js"></script>
```

## Register the element (npm)

```ts
import { registerReviewWidget } from "@ethioreview/review-widget-web-vanilla";

registerReviewWidget();
```

## Copy-paste — dashboard widget (recommended)

```html
<script async src="https://cdn.ethioreview.com/widget.js"></script>
<review-widget
  data-base-url="https://api.ethioreview.com"
  data-public-key="pk_live_YOUR_KEY"
  data-widget-id="YOUR_WIDGET_ID"
></review-widget>
```

`data-publishable-key` is an alias for `data-public-key`.

## Manual organization embed

```html
<review-widget
  data-base-url="https://api.ethioreview.com"
  data-public-key="pk_live_YOUR_KEY"
  data-business-id="YOUR_ORG_PROFILE_ID"
  data-limit="5"
></review-widget>
```

## Telemetry events

```js
document.querySelector("review-widget")?.addEventListener("widget-telemetry", (e) => {
  console.log(e.detail);
});
```

Events: `onLoad`, `onError`, `onInteraction`.

## One failure mode

**Script loads but element stays empty** — confirm `data-public-key` is set, the origin is allowlisted, and (when using `data-widget-id`) the widget environment matches the key prefix.
