The **Review Widget** displays your organization's best reviews — star rating, reviewer name, avatar, and review text — with each testimonial linking to the full review on EthioReview.

## Who this is for

Marketing sites, product pages, government portals, and marketplace storefronts that want trusted EthioReview social proof without building a custom reviews UI.

## Features

- Top-rated filter (default 4+ stars, `sort=top`)
- Public reviewer info only (name, avatar, influencer badge)
- Click-through to `/organizations/{slug}/reviews/{id}` (sandbox uses `/sandbox/organizations/...`)
- Production + sandbox environments
- CORS locked to your allowed origins

## Public API endpoints

Base URL: `https://api.ethioreview.com/api/v1`

| Method | Path | Auth |
| ------ | ---- | ---- |
| GET | `/widgets/businesses/{orgId}/reviews` | `X-Widget-Key` |
| GET | `/widgets/businesses/{orgId}/rating` | `X-Widget-Key` |
| GET | `/widgets/resolve/{widgetId}` | `X-Widget-Key` |

## Dashboard setup

1. **Integrations → API keys** — create client, copy `pk_*` key (secret shown once)
2. **Integrations → Review widgets** — configure layout, min stars, link matching-environment client
3. **Integrations → Sandbox test** — preview and copy snippets (sandbox only)
4. Paste into your site or use an SDK guide below

## Copy-paste starter

```html
<script async src="https://cdn.ethioreview.com/widget.js"></script>
<review-widget
  data-base-url="https://api.ethioreview.com"
  data-public-key="pk_test_YOUR_KEY"
  data-widget-id="YOUR_WIDGET_ID"
></review-widget>
```

## One failure mode

**Blank widget with CORS errors** — add your exact site origin under **Integrations → API keys**. See [Allowed origins](/api-keys/allowed-origins).

## Marketplace pages

Multi-vendor partners embed the widget on **platform** and **shop** pages (`businessId` = marketplace or vendor org, `pk_test_*` in sandbox). Product SKU pages should use the partner SSR API so ratings stay product-scoped — see [Digital platforms](/integrations/digital-platform/overview).
