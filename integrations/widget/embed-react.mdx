`@ethioreview/review-widget-react` is the recommended embed for React SPAs and component libraries. It ships layout components and a data-fetching `ReviewWidget` container.

## Who this is for

React / Vite / CRA apps (use [Next.js embed](/integrations/widget/embed-next) when you need SSR + JSON-LD).

## Dashboard steps

1. **Integrations → API keys** — create `pk_test_*` or `pk_live_*`
2. Add your app origin to allowed origins
3. **Integrations → Review widgets** — create a matching widget and copy `widgetId`
4. Optional: copy the React snippet from **Integrations → Sandbox test**

## Install

```bash
npm install @ethioreview/review-widget-react @ethioreview/review-widget-core
```

```tsx
import "@ethioreview/review-widget-react/styles.css";
```

## Copy-paste — dashboard widget

```tsx
import { ReviewWidget } from "@ethioreview/review-widget-react";
import "@ethioreview/review-widget-react/styles.css";

export function Testimonials() {
  return (
    <ReviewWidget
      baseUrl="https://api.ethioreview.com"
      publicKey="pk_live_YOUR_KEY"
      widgetId="YOUR_WIDGET_ID"
    />
  );
}
```

`publishableKey` is an alias for `publicKey`.

## Environment variables

```bash
VITE_ETHIOREVIEW_API_URL=https://api.ethioreview.com
VITE_ETHIOREVIEW_PUBLIC_KEY=pk_test_YOUR_KEY
VITE_ETHIOREVIEW_WIDGET_ID=YOUR_SANDBOX_WIDGET_ID
```

```tsx
import { createReviewWidgetConfig, ReviewWidget } from "@ethioreview/review-widget-react";

const config = createReviewWidgetConfig({
  baseUrl: import.meta.env.VITE_ETHIOREVIEW_API_URL,
  publicKey: import.meta.env.VITE_ETHIOREVIEW_PUBLIC_KEY,
  widgetId: import.meta.env.VITE_ETHIOREVIEW_WIDGET_ID,
});

export function Testimonials() {
  return <ReviewWidget {...config} />;
}
```

## Manual layout (no registry widget)

```tsx
<ReviewWidget
  baseUrl="https://api.ethioreview.com"
  publicKey="pk_live_YOUR_KEY"
  businessId="YOUR_ORG_PROFILE_ID"
  layout="trust-score"
  minStars={4}
  limit={5}
/>
```

## One failure mode

**Styles missing** — you forgot to import `@ethioreview/review-widget-react/styles.css` in the app entry. Layouts render unstyled or collapsed until the CSS is loaded.
