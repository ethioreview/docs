---
title: Widget setup checklist
description: Step-by-step dashboard workflow for embedding the review widget.
---

Use this checklist to go from zero to a production embed. All clicks are under **Integrations** in the [business dashboard](https://app.ethioreview.com).

<Steps>
  <Step title="Confirm plan includes API access">
    Widget and API key features require `api_access` on your subscription plan.
  </Step>
  <Step title="Create SANDBOX API key">
    **Integrations → API keys → Create**

    - Environment: **SANDBOX**
    - Allowed origins: localhost and staging URLs
    - Save `pk_test_*` and `sk_test_*` (secret shown once)
  </Step>
  <Step title="Create SANDBOX review widget">
    **Integrations → Review widgets → Create**

    - Environment: **SANDBOX**
    - Link to the sandbox API client
    - Set min stars (4+) and limit
  </Step>
  <Step title="Preview in Sandbox test">
    **Integrations → Sandbox test** — select the client and widget, confirm synthetic reviews, copy snippets. Add the dashboard origin to allowed origins if the preview is blank.
  </Step>
  <Step title="Embed on staging">
    Use the copied snippet or React / Next.js package. Verify synthetic reviews load on your staging domain.
  </Step>
  <Step title="Create PRODUCTION API key">
    **Integrations → API keys → Create**

    - Environment: **PRODUCTION**
    - Allowed origins: production domain(s) only
  </Step>
  <Step title="Create PRODUCTION review widget">
    **Integrations → Review widgets → Create** — environment **PRODUCTION**, linked to the production client.
  </Step>
  <Step title="Deploy">
    Replace `pk_test_*` with `pk_live_*` and the production `widgetId` in your production build. Never deploy secrets to the browser.
  </Step>
  <Step title="Monitor">
    Check API client `lastUsedAt` in **API keys**. Watch for `403` origin or environment mismatches in your logs.
  </Step>
</Steps>

## Environment match reminder

| Key | Widget |
| --- | ------ |
| `pk_test_*` | Sandbox review widget only |
| `pk_live_*` | Production review widget only |

## Common issues

| Problem | Fix |
| ------- | --- |
| CORS / 403 Origin | Add exact origin under **API keys** ([guide](/api-keys/allowed-origins)) |
| Empty reviews | Production org may have no ACTIVE 4+ star reviews yet — keep verifying in sandbox |
| Widget misconfigured | Ensure `data-public-key` and `data-widget-id` (or `data-business-id`) are set |
| Environment mismatch | Key prefix and widget environment must match |
