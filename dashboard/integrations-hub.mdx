The **EthioReview dashboard** (separate from this docs site) is where your team performs setup. This developer portal explains *how*; the dashboard is where you *do* it.

Open [https://app.ethioreview.com](https://app.ethioreview.com) → **Integrations**.

## Integrations sections

| Section | What you do here |
| ------- | ---------------- |
| **API keys** | Create **SANDBOX** (`pk_test_*`) or **PRODUCTION** (`pk_live_*`) clients; set allowed origins; rotate/revoke. Secret shown **once**. |
| **Review widgets** | Register embed configs, link to a matching-environment API client, copy widget IDs |
| **Sandbox test** | Live preview of synthetic testimonials; copy org ID, publishable key, and HTML/React/iframe snippets |
| **Digital platform** | Marketplace sandbox keys, scopes (`marketplace:shops`), SSR helpers, docs links |
| **Telegram** | Generate link codes, view connection status, collection URLs, notifications |

## Environment match

When you create a review widget, its environment must match the API client you link:

- Sandbox widget ↔ `pk_test_*` only
- Production widget ↔ `pk_live_*` only

**Sandbox test** only lists sandbox clients and sandbox widgets.

## Link from your product

Point integrators to:

- **Docs**: `https://docs.ethioreview.com`
- **Dashboard**: `https://app.ethioreview.com` → **Integrations**
- **Get sandbox keys (docs)**: [/api-keys/create-sandbox](/api-keys/create-sandbox)

## Permissions required

Org **admin** access is typically required to create API keys, register widgets, and link Telegram groups. Exact roles are configured in your EthioReview organization settings. Widget and partner APIs also require plan feature `api_access`.
